1.Tietoja sovelluksesta
Kauppalista 2.0 on sovellus, joka on paranneltu versio kurssin ensimmäisessä projektissa luodusta kauppalistasta. Yksinkertaisuudessaa kauppalistaan lisätään tuotteita, ja listassa olevia tuotteita voi poistaa ja muokata niin halutessaan.

2.Tunnetut virheet/bugit
En ole onnistunut löytämään bugeja sovelluksen toiminnoista.

3.Teknologiat
Koko projekti on tehty html tiedostoon. HTML avulla on luotu rakenne sovellukselle. Sovelluksen ulkonäkö on luotu bootstrapilla: <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">". Listan toiminnallisuus tulee jquerylla: <script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>

4.Asennus
Kauppalista 2.0 voi lisätä tuotteita kirjoittamalla kenttään haluamansa tuotteen, ja painamalla enteriä tai "Lisää" painiketta. Lisäyksen jälkeen lisäyskentän alapuolelle tulee 3 sekunnin ajaksi ilmoitus tuotteen lisäyksestä, ja sen saa halutessaan heti pois painamalla ilmoituksen oikeasta yläkulmasta ruksia. Mikäli tuotteen nimi on liian lyhyt (alle 2 merkkiä) käyttäjä saa ilmoituksen, että tuotteen nimen on oltava vähintään 2 merkkiä.  Listassa olevia tuotteita voi muokata painamalla kynän kuvaa, jolloin kyseisen tuotteen nimi tulee aktiiviseksi ja sitä pääsee muokkaamaan. Muokkaus vahvistetaan painamalla enteriä tai painetaan hyväksy täppää kentän oikeasta reunasta. Muokkauksen voi myös hylätä painamalla esc-painiketta. Muutoksen onnistumisesta tulee ilmoitus onnistuneesta muutoksesta 3 sekunnin ajaksi.
